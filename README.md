# JB Studio — Sports Design Portfolio

Static HTML/CSS/JavaScript website. No build process or dependencies required.

## Local preview
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Files
- `index.html` — redesigned homepage (hero, work preview, services, inquiry)
- `work.html` — placeholder for future full portfolio
- `about.html` — placeholder for future about page
- `style.css` — shared styling, responsive layouts, #00FF00 accents
- `script.js` — mobile menu, footer year, and form preview handling
- `assets/` — future project images

## Important before launch
- Artwork currently consists of CSS-based placeholders. Replace with actual original work.
- The inquiry form does **not** send messages yet. Connect Netlify Forms or another submission service before publishing it as a working booking form.
- Google Fonts requires an internet connection; local fallbacks are provided.

## Updating your local folder
Copy these files into `Documents/sports-design-portfolio`, replacing the previous versions. Do not create a nested folder with the same name.
